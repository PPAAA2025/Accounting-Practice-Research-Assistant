# 会计实务检索助手

面向财务人员的会计实务历史答疑检索工具，收录陈奕蔚在中国会计视野论坛的公开答疑原文。

## 在线使用

页面发布后可通过 GitHub Pages 访问：

<https://ppaaa2025.github.io/Accounting-Practice-Research-Assistant/>

## 本地打开

直接打开 `index.html` 即可使用。页面为纯静态文件，不需要后端服务。

## 数据说明

本工具只做检索与整理，不做判断。检索结果是论坛历史答疑原文，可能不适用于当前具体情形，也不代表原答疑者对当前问题的意见，不构成专业结论。重要事项请核对最新准则原文并咨询专业人士。

## 数据覆盖与更新

主库按关键词检索整理；《计学撮要》专题另依据数据源的引用反查接口建立原帖索引。界面会区分已收录完整答疑与仅有原帖索引的条目，引用索引不是书籍原文，也不能替代打开论坛原帖核对版本与上下文。

在 Windows 安装 Python 3 后，可运行 `python supplement_jixue.py` 刷新引用索引；如需补抓完整答疑，运行 `python supplement_jixue.py 100`，数字表示本次最多处理的帖子数。脚本每 20 帖保存一次，可重复运行续补。完成数据更新后运行 `python build_datajs.py` 重建页面所用的数据脚本。
